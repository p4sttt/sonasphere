# stdlib — стандартная библиотека sona

Написана на самом языке sona: инструменты и эффекты (как описания DSP-графов), гаммы, раскладки
драм-китов, вспомогательные паттерны. sona компилирует её при старте и загружает инструменты в bitvm
как GraphDef. В самом bitvm встроенных инструментов нет — только юниты.

Пусто, пока не спроектирован язык (`docs/architecture.md`, §9).
